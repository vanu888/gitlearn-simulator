# GitLearn: Interactive Git & GitHub Simulator 🐙

GitLearn is a browser-based, interactive learning platform designed to teach practical version control workflows. Instead of just reading about Git commands, users can type them into a simulated terminal or click through a recreated GitHub web interface to build muscle memory.

## 🚀 Live Demo
[**Play the Simulator Here**](https://vihangaanuththara.me/gitlearn-simulator/) 


## ✨ Features

The application is divided into two core learning modules:

### 1. Terminal Training (CLI Mode)
A fully functional fake terminal that validates user input against a predefined curriculum. It guides users through version control for a **Python Machine Learning project**, covering:
* Repository initialization (`git init`)
* Staging and committing (`git add`, `git commit`)
* Branching and switching (`git branch`, `git checkout`)
* Merging features (`git merge`)
* Reviewing history (`git log`)
* Pushing to remotes (`git remote`, `git push`)

### 2. GitHub GUI Training (Web Mode)
A faithful recreation of the GitHub Primer dark-mode UI. It simulates managing a **Mobile Application Development repository**, teaching users how to:
* Create new repositories
* Unlock the "Profile README" secret
* Add standard Open Source Licenses (`LICENSE` files) via the browser
* Open, review, and merge Pull Requests

## 🛠️ Tech Stack
This project was built entirely from scratch without external frameworks to ensure lightweight, fast performance:
* **HTML5** (Semantic structuring and layout)
* **CSS3** (Custom variables, Flexbox, UI cloning of GitHub Primer Dark Theme)
* **Vanilla JavaScript** (State management, DOM manipulation, command validation)
